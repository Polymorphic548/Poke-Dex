# Pokédex – Pokémon Encyclopedia

A fan-made Pokédex web application developed using **HTML, CSS, and JavaScript**. This project was created as a personal hobby and learning experience to explore front-end web development while recreating the experience of browsing and discovering Pokémon.

The project is intended purely for **educational, personal, and non-commercial purposes**.
